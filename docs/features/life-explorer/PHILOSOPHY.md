# LIFE EXPLORER — NORTH STAR

**Last Updated:** August 23, 2026  
**Status:** Active

## What we are building

A **tool-enabled human**.

Not a child who rented facts for a test and returned them. A person who can notice what he needs, pick up a tool, and learn it — a book, a globe, ice in a bowl, a person, VIVA.

School trained most of us to memorize on command, prove it once, and forget. The world after 18 does not work that way. Tools do the sounding-out, the perfect sentence, the second explanation. The human decides what is worth learning and uses the tool until it lives in the body.

VIVA is the composer in the product. In the UI it is always **VIVA**, never “AI.” Under the hood it is a tool, the same as a book with audio.

## Nothing here is locked

Those ideas were then written into agent rules as **hard law** — “Life Explorer is the curriculum,” “we do not follow anyone else’s program,” “you’ve already decided.”

That voice was the docs, not a parent decree. This file replaces it.

**Working bets** can change the moment they stop serving the child. **Engineering conventions** (where prompts live, do not invent URLs, do not edit the schema dump) stay so the software does not lie or break. Do not confuse the two.

Agents: do not say “you’ve already decided” about pedagogy. If a bet is in the way, say so and change it.

## The important things

Keep the stack small. Automatic tools first. Just-in-time knowledge when a real question demands it.

At this age the tools are:

- Decode print so a book can be used, not worshipped
- Number sense that works on snacks, ice, coins
- Say a true thing in a sentence, then three
- Ask a real question and go find out
- Make a thing and talk about what happened

If those are in the body, late continents are fine. If those are wobbly and he can name a glacier, we built scenery.

Fun is how we meet the work. Retrieval (Flashback) is how we keep it. Use-in-a-new-situation is the only test that matches adult life.

## Layered books

A book is a tool with layers, not a single frozen page. VIVA can author a story once and ship it as:

1. **The story** — plain text, hear-it audio
2. **Words sounded out** — the same sentences with phonemes / blending visible and spoken, so decoding is a tool he can see
3. **Sentence structure** — the same sentences taken apart (who did what, capital, end mark) with audio, so grammar is an example he can hear, not a worksheet he has to survive

Any lesson may use a generated book, a library book, a booster reader, or a backyard. No publisher owns the year. No rule forbids a good page from somewhere else.

When a book is the tool, prefer a layered VF book so the child can flip between *meaning*, *sound*, and *structure* on the same story.

Story pages use a two-pass read: first pass is a cold record with no help; second pass lets him tap a word or play the sentence, then record again. The page scores the attempt — not a specialist with a clipboard.

## Working bets (current school shape)

These are how we run today. They are not commandments.

- **Life I Choose** — why the day exists. Parent current-state profile → VIVA draft → child edits until it is his.
- **Expedition** — one real world at a time. Reading, math, making, science can live inside it. They do not have to all live in every day.
- **World Map + year arc** — a map of tastes we might take. Ours to edit. Other people’s unit lists are allowed as ingredients, not as the boss.
- **Ladders** — a hypothesized sequence for reading, math, writing. Climb when a rung is secure enough to try in a new situation. If a better sequence shows up, change the ladder.
- **Flashback** — 2 minutes of spaced retrieval from Learned. This is the keep engine.
- **Life Learning** — small year-long practice (sight words, time, money, life sentences, facts, compass). Automaticity without a “Money Week” that dies in October.
- **Wonder Wall** — Know / Wonder / Learned in his language. Wrong Know stays until he replaces it.
- **Semester mix** — current grade first; next grade woven in where this grade is already easy. A pacing bet, not a law.
- **Three cards** (comfort / stretch / unknown) when picking a new world — a discovery bet so the map does not shrink to what he already loves.
- **12 Life Categories** — vision ingredients and a weekly compass lens, not the calendar.
- **Fun Contract** — hook, mission, body, artifact, choice, celebration. Current lesson shape. If a day needs a different shape, change the contract.
- **Florida ledger** — derived weather from what we lived, so the parent is not filling a standards form. Portfolio route, not exam-as-product.

```
Life I Choose → VIVA composes a day (tools + world + current skills)
  → child uses the tools
  → check: can he try this in a new situation?
  → keep, rest, or climb
```

## Parent experience

Still the job: simplify the adult’s life.

Open today. Short prep list. Materials. Follow the day. Ask VIVA / Another way. Two-minute check-in. Next day is new.

The parent should not have to hunt, or run a second school “to be safe.” They also should not be told a boxed book is illegal. If a Good and the Beautiful reader or a library decodable matches the skill in front of him, use it. If VIVA can make a better layered book in five minutes, use that.

## What we refuse (values, not curriculum law)

- Do not tell the parent they are behind.
- Do not make the evaluation the product. The ledger follows the life.
- Do not invent a book title, URL, page number, or runtime. If we did not make it and we do not have the link, say so.
- Do not clone yesterday and call it a new day.
- Do not treat more pages as more learning.
