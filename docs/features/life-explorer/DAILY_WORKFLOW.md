# DAILY PLANNING WORKFLOW

Follow this sequence each time a lesson is created or updated.

1. Load the active student profile, including **Life I Choose**.
2. Load the active Expedition and its `why_this_matters`.
3. Load the World Map (honest hits only) and the year arc / current semester.
4. Load current ladder rungs — math, reading, and writing (do not climb until secure; mix next grade only if semester 2 and this grade is secure). Pick **one** rung for today's foundational block, rotating domains.
5. Load the weekly Life Learning focus and the Year Map steers (untouched Big Ideas) — weave in only when today's topic honestly allows.
6. Load the current Wonder Wall.
7. Load recent lessons — titles, hooks, missions, artifacts — so today is **not** a clone of yesterday.
8. Review incomplete high-interest questions.
9. Review foundational skills that are still wobbly.
10. Check which approved resources and materials are available (forecast + pantry).
11. Generate one complete unique lesson (per [LESSON_CONTRACT.md](./LESSON_CONTRACT.md)).
12. Distinguish core activities from optional extensions.
13. Produce the parent preparation checklist.
14. Produce the child documentation expectations (child output).
15. After the lesson, request a very short parent check-in — including: clicked enough to try in a new situation?
16. Update:
    - Wonder Wall
    - Completed activities
    - New questions
    - Learning evidence
    - Skill observations (`emerging | developing | secure | needs_support`) — ladder rungs, Life Learning rungs, and Compass slices alike
    - Recommended next direction
17. Generate the next lesson only after incorporating those updates. Wobbly work returns in a **new unique** day.

## Two-Minute Lesson Check-In

1. What did Oliver enjoy most?
2. What did he create, say, or demonstrate?
3. What felt too easy or too difficult?
4. What new question did he ask?
5. Should we continue this topic tomorrow?
6. Did this rung click enough to try in a new situation? (If no: stay. If yes: mark secure.)

Optional: Upload a photo, drawing, writing sample, or recording.

Convert the informal response into structured records automatically:

- New wonder items from question #4
- Learned items when discoveries are stated
- Learning evidence from #2 + optional upload
- Skill progress notes from #3 and #6 (ladder keys when the work was a rung; Life Learning rung keys and Compass slices when those were lived)
- Expedition direction: continue / deepen / change from #5
- Recommended next action for the next generate call

## Parent-facing surfaces

Keep the interface simpler than the database.

**Today** shows:

- Why (from Life I Choose / `why_this_matters`) — not a life-category label
- Expedition + lesson title
- Prep / lesson / reading / foundational time summary
- One experiment / one journal when present
- Buttons: Start Lesson, Open Resources, Record What Happened, Change Direction, Wonder Wall, Ask VIVA

**Wonder Wall tabs:** Know, Wonder, Learned

**World Map:** Sky, Earth, Water, Motion, Living, Places, Making, People — tastes, not a 12-category calendar

**Progress:** Strong vs wobbly across math, reading, and writing, Life Learning weather, plus the sem-1 / sem-2 aim — not gold stars for covering. Evaluation readiness is a derived rollup with an anniversary countdown — never a form.

**Florida ledger:** Weather derived from evidence, ladders, and the activity log

**New direction:** VIVA's three suggestion cards — comfort, stretch, unknown. The unknown card draws from unvisited World Map clusters and untouched Year Map ideas.
