# DAILY PLANNING WORKFLOW

Follow this sequence each time a lesson is created or updated.

1. Load the active student profile.
2. Load the active Expedition.
3. Load the current Wonder Wall.
4. Load the most recent lesson record.
5. Review incomplete high-interest questions.
6. Review foundational skills needing practice.
7. Check which approved resources and materials are available.
8. Generate one complete lesson (per [LESSON_CONTRACT.md](./LESSON_CONTRACT.md)).
9. Distinguish core activities from optional extensions.
10. Produce the parent preparation checklist.
11. Produce the child documentation expectations (child output).
12. After the lesson, request a very short parent check-in.
13. Update:
    - Wonder Wall
    - Completed activities
    - New questions
    - Learning evidence
    - Skill observations
    - Recommended next direction
14. Generate the next lesson only after incorporating those updates.

## Two-Minute Lesson Check-In

1. What did Oliver enjoy most?
2. What did he create, say, or demonstrate?
3. What felt too easy or too difficult?
4. What new question did he ask?
5. Should we continue this topic tomorrow?

Optional: Upload a photo, drawing, writing sample, or recording.

Convert the informal response into structured records automatically:

- New wonder items from question #4
- Learned items when discoveries are stated
- Learning evidence from #2 + optional upload
- Skill progress notes from #3
- Expedition direction: continue / deepen / change from #5
- Recommended next action for the next generate call

## Parent-facing surfaces

Keep the interface simpler than the database.

**Today** shows:

- Expedition + lesson title
- Prep / lesson / reading / foundational time summary
- One experiment / one journal when present
- Buttons: Start Lesson, Open Resources, Record What Happened, Change Direction, Wonder Wall

**Wonder Wall tabs:** Know, Wonder, Learned  

**Portfolio:** Photos, Writing, Experiments, Builds, Presentations  

**Progress:** Calm counts (practice frequency, questions generated, strongest interest) — not grades.
